# Anime Portfolio - Frontend (React + Vite)

Frontend client for the Cyber Anime Portfolio.

## Features
- **Cinematic 7-Second Intro Loader**: Plays background eye animation with zero media controls or audio, auto-transitioning with an optic anime slash effect.
- **Cyberpunk / Anime HUD Theme**: Custom design system using Orbitron, Rajdhani, and Noto Sans JP fonts.
- **Interactive Shinobi Cards**: Profile stats and live Express API status.

## Development
```bash
npm install
npm run dev
```
